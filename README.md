# 🎮 Python Arcade

### An Interactive Multi-Game Desktop Application Using Python and Tkinter

Python Arcade is a desktop gaming application developed using **Python and Tkinter**. It brings multiple mini-games together into one interactive arcade-style application with a dark neon gaming interface.

This project was created as a **CA 2 Python project** to demonstrate practical Python programming concepts through an interactive graphical application.

---

## 🎮 Games Included

Python Arcade currently contains **8 interactive mini-games**:

1. 🔢 **Number Guess**
2. ✊ **Rock Paper Scissors**
3. 🐍 **Python Quiz**
4. 🧮 **Math Challenge**
5. 🔤 **Word Guess**
6. 🧠 **Memory Challenge**
7. 🔮 **Number Sequence**
8. 📈 **Higher or Lower**

---
